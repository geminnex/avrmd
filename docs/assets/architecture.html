/api/assist → OpenRouter EXTERNAL, OPTIONAL
The only outbound call in the request path — and only when the local match is weak and a key is configured. 2.5s timeout, no retry, no paid fallback. It returns catalog-vocabulary filters, never answer text; the same local engine re-runs with them. With no key set, this box is simply never reached.
Read order: a visitor's request never crosses more than the App Router and the domain layer — the data layer is files, not a service, so there is nothing to keep warm and nothing between visitor and page that can go down independently. The discovery job and OpenRouter are the only two paths that leave the server, and both are additive: the site is fully functional with the timer disabled and no API key set.
